# Dream 模型共振選股系統（GitHub Pages）

此版本加入多檔股票手動輸入、共振評分與排名。

## 使用方式
1. 輸入股票代號／名稱、收盤價、支撐、壓力、防守／停損價。
2. 選擇走勢斜率與交易狀態。
3. 設定帳戶資金、單筆風險上限與最低評分門檻。
4. 按「執行 Dream 共振評分」。可新增或移除股票。

預設的 2303 聯電、2408 南亞科、2492 華新科只是空白範例，不是即時推薦。

## 示範評分規則
- 框架位置最高 40 分；斜率最高 30 分；資金紅綠燈最高 30 分。
- 跌破支撐或防守價時標記框架失效。
- 中性或逆風狀態縮減部位；斜率走平再縮減，斜率轉弱則部位試算為 0。
- 第一目標為參考進場價＋1R，第二目標為參考進場價＋2R。

這是透明的示範規則，並非經回測驗證的預測模型。目標價不是價格預測，也不代表應立即交易。

## 更新現有 GitHub Pages 網站
1. 解壓縮 ZIP。
2. 在現有 Repository 上傳並覆蓋 `index.html`、`style.css`、`app.js`、`README.md`。
3. Commit changes 到 `main`，等待 Pages 部署完成，再重新整理網站。

本專案使用純 HTML/CSS/JavaScript，不需要建置工具或 API 金鑰。

## 限制與風險
- 不會自動連接即時行情或掃描全市場；行情由使用者自行輸入並核對。
- 部位估算採整張（1,000 股）簡化方式，未計交易成本、滑價、跳空與流動性。
- 僅供教育、研究與風險管理用途，不構成投資建議。
