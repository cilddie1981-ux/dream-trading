Dream 掃描按鈕修正版

請在 GitHub 專案中替換這兩個檔案：
1. index.html
2. app.js

步驟：
1. 解壓縮 ZIP。
2. 在 GitHub 的 dream-trading 專案中，分別打開 index.html、app.js，點鉛筆編輯。
3. 將原檔內容全部替換成 ZIP 裡同名檔案的完整內容。
4. 分別 Commit changes。
5. 等 GitHub Pages 部署完成後，開啟：
   https://cilddie1981-ux.github.io/dream-trading/?v=5
6. 按「執行 Dream 共振評分」測試。若尚未填寫個股價格，應該會在結果區顯示提示，而不是毫無反應。

注意：本工具是手動輸入資料的評分器，不會自動抓即時行情或掃描全市場。
