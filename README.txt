Dream V3 掃描無反應修正版

請只替換以下兩個檔案：index.html、app.js（style.css 不用改）。
1. GitHub repo 打開 index.html，Edit，全選貼上 ZIP 內新版，Commit。
2. 打開 app.js，同樣全選貼上新版，Commit。
3. 部署後開啟 https://cilddie1981-ux.github.io/dream-trading/?v=6
4. 畫面會顯示「系統程式已載入」或具體錯誤；按「更新全市場資料」會顯示 API 連線狀態。
5. 若官方行情 API 因 CORS 或服務暫停失敗，按鈕仍會有狀態提示，可用 CSV 匯入；這不代表已取得全市場資料。
